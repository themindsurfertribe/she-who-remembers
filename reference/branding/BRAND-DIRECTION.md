## TYPOGRAPHY DIRECTION

Display / Headings:
Cinzel or a visually similar elegant high-contrast serif.

Body:
Lora or another highly readable editorial serif.

UI / Navigation / Labels:
Montserrat or another clean sans serif.

Do not hard-code font choices throughout components.
Use centralized design tokens.

## SYMBOLIC LANGUAGE

Primary motifs:
- sacred geometry
- lotus
- serpent
- lioness
- sun
- moon
- radiance / light

Do not use every symbol simultaneously.

Use motifs sparingly.

The website should feel sophisticated and editorial, not like a metaphysical gift shop.

## CORE DESIGN PRINCIPLE

Mysticism provides atmosphere.
Editorial restraint provides credibility.

Suggested visual balance:
- 70% clean editorial elegance
- 20% cosmic / sacred atmosphere
- 10% dramatic visual moments
